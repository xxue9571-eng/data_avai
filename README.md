# 发电系统可靠性评估逆问题：原始数据与求解代码

本仓库提供论文《发电系统可靠性评估逆问题解析表征及求解方法》的算例原始数据与 MATLAB 求解代码。

用于求解发电系统可靠性约束下的最低投资机组配置问题。机组采用相互独立的正常运行、停运两状态模型。

## 文件

| 文件 | 内容 |
| --- | --- |
| `原始数据.xlsx` | 论文算例的原始数据 |
| `run_CNDP.m` | 大小系统数据、工况设置、调用求解和显示结果 |
| `CNDP.m` | 容量分布卷积、反向 Bellman 递推和最优配置恢复 |

数据已写入输入脚本，只需运行 `run_CNDP.m`，它会调用 `CNDP.m` 完成求解。

## 运行

在 MATLAB 中将当前文件夹切换到本目录，打开 `run_CNDP.m`，修改开头的算例名称：

```matlab
case_id = 'small';   % 小系统；大系统填 'large'
```

然后点击“运行”，或在命令窗口执行：

```matlab
run_CNDP
```

`run_CNDP` 是脚本，算例和参数在文件内修改。

## 修改数据和工况

在选中的 `case 'small'` 或 `case 'large'` 分支中编辑数据：

| 变量 | 每行含义 |
| --- | --- |
| `base` | 一台现有机组的 `[容量/MW, 停运率]` |
| `candidate` | 一台候选机组的 `[容量/MW, 停运率, 投资]` |
| `scenarios` | 一个工况的 `[目标负荷/MW, LOLP限值]` |

容量按 **1 MW** 离散，容量列填写整数；停运率填写概率。投资单位为小系统的**百元**、大系统的**千元**。候选机组按矩阵行号编号为 C01、C02……，每台只能安装一次。大系统的 `base` 由 `area` 重复三次组成，共96台现有机组。

例如，小系统的多个工况可以直接写为：

```matlab
scenarios = [
    1400, 1e-3;
    1700, 1e-3;
    1700, 5e-4
];
```

已有机组矩阵时，也可以直接调用核心函数：

```matlab
result = CNDP(base, candidate, target, alpha);
```

## 查看结果

运行后，`summary` 汇总所有工况的配置、投资、ERC、LOLP和求解时间；`results{k}` 保存第 k 个工况的详细结果。工作区中的 `result` 为最后一个工况。

| 结果字段 | 含义 |
| --- | --- |
| `feasible` | 是否存在可行配置 |
| `cost` | 最低新增投资 |
| `selection` | 安装选择，`true` 表示安装对应行的候选机组 |
| `capacity` | 配置后的总装机容量，MW |
| `ERC`、`LOLP` | 最优配置的可靠性指标 |
| `pmf` | 最优配置的容量概率分布，第 k+1 项对应 k MW |
| `V`、`policy` | 各阶段的价值函数表和安装决策表 |
| `path_value` | 最优配置路径上的最低后续投资，按阶段1至M排列 |
| `stage` | 各阶段卷积次数、累计次数及卷积耗时 |
| `feasible_count`、`convolutions` | 可行配置数、构建候选配置时的总卷积次数 |
| `time` | 本工况总求解时间，秒 |

```matlab
r = results{1};
find(r.selection)    % 选中的候选机组编号
r.stage             % 阶段计算统计
```

`stage` 中的耗时按候选机组阶段编号汇总，仅统计构建配置时的卷积操作，单位为秒。无可行解时，`feasible` 为 `false`，`cost` 为 `Inf`。

## 求解过程与基准结果

程序从现有系统分布出发，逐台扩展安装与不安装两种选择，计算各配置的可靠性

以下基准工况均取 `alpha = 1e-3`：

| 系统 | 目标负荷/MW | 新增台数 | 最低投资 | ERC/MW |
| --- | ---: | ---: | ---: | ---: |
| 小系统 | 1400 | 9 | 3109百元 | 1400 |
| 大系统 | 10000 | 9 | 1496千元 | 10003 |
